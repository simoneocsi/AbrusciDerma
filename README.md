# Abrusci Derma — nuovo sito

Homepage Next.js responsive con tema intercambiabile `dark` / `sage`.

## Avvio
```bash
npm install
npm run dev
```
Apri http://localhost:3000.

## Tema
Il tema iniziale è `dark`. Il selettore nell'header permette di passare a `sage`. I token cromatici sono centralizzati in `app/globals.css` tramite variabili CSS su `main` e `main[data-theme="sage"]`.
